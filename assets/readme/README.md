# assets/readme

Glitch-punk SVG components used by the profile README. Generated by `scripts/readme_art.py`
(tokens: `GLITCH` in `scripts/theme.py`); edit the generator, not the files.

| Folder | Contents |
|---|---|
| `headers/` | `title.svg` (RGB-split hero) and one numbered bar per README section |
| `dividers/` | glitch, red-cyan, scanline and angular rules |
| `frames/` | dossier title/footer bars and featured-project card edges |
| `tags/` | project tiles, Hexaware metric tiles, role/date/award pills, tech category labels |

All files are self-contained, with `<title>` and alt text. Palette: ink `#0d0d2b`, panel `#161b22`,
red `#ff0033`, cyan `#00e5ff`, magenta `#e6007e`.
